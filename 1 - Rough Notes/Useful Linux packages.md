# Useful Linux packages

## rg(ripgrep)

- ripgrep is just better grep

## fd(find)

- fd is a better find command. Used mainly to find files

## tmux

- The holygrail of multitasking development in linux

## gh cli

- Github in cli. Alows to create repos and to do pull requests, look at open issues and anything that would be allowed in github.com be done inside the terminal

## doppler cli

- allows to add secrets easily to software. allows to for example run software without having to store secrets like .env while also running the code by accessing the secrets with no issues without having to expose the secrets
- an additional layer of ease and security

## pass

- It saves passwords and secrets using git and to use passwords easily
- password store

## jq

- makes json easy to work with
- can pull data and can perform transformations

## stow

- allows to make symbolic links
- best for managing dotfiles

## fzf

- fuzzy finder for command line
- best when combined with tools like passwordstore or zsh for autocompletion
